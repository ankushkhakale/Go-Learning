# slop-pr-demo

This directory is intentionally added for a **dummy/test pull request** to exercise PR workflows.

The Go examples here are deliberately low-value and intentionally sloppy (redundant comments, repetitive code, overly verbose names, and simplistic output). They are **not** production-ready and are only meant as harmless short standalone programs for testing review/CI/PR flow behavior.

Included tiny examples:

- `hello-world/`
- `even-odd-checker/`
- `number-to-word/`
- `slice-printer/`
- `trivial-calculator/`
